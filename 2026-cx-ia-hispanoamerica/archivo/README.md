# Versiones históricas

Estos archivos documentan la evolución del estudio. No son el instrumento ni el protocolo activos. Algunas versiones incluían Brasil, portugués, más preguntas o decisiones de interfaz luego sustituidas.

- `instrumentos/`: versiones anteriores a 0.6.
- `manuscrito-v1/`: primera versión integrada, antes de ampliar agentes y cierre de ciclo.
- `metodologia/`: propuesta inicial de aplicación; el método vigente está en el manuscrito v2.
- `infraestructura/`: propuesta histórica de infraestructura independiente.
- `diseno/`: dirección y parámetros de diseño.

Se preserva el contenido científico histórico; las rutas locales se adaptan para portabilidad y los inventarios privados y capturas de prueba no se distribuyen.
