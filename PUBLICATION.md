# Publicación, procedencia y materiales

Este repositorio permanece privado. La primera incorporación fue preparada sin credenciales ni respuestas de participantes, para facilitar una futura apertura. Esto no sustituye la revisión de cada contribución posterior.

## Qué incluye

- Manuscrito y sus fuentes editables, referencias bibliográficas y metadatos.
- Instrumento vigente, versiones anteriores identificadas como históricas, cobertura y antecedentes metodológicos.
- Código del cuestionario, contrato Zod, backend, migraciones, pruebas e infraestructura declarativa.
- Scripts portables para regenerar el manuscrito y exportar el instrumento.
- Resúmenes operativos sin inventarios privados ni datos individuales.

Los documentos archivados conservan decisiones anteriores, incluidos Brasil y portugués. No describen el alcance vigente, que se establece en el manuscrito v2 y el instrumento 0.6. Las versiones se preservan para trazabilidad, no como instrumentos simultáneamente activos.

## Material conservado fuera del repositorio

| Material local | Tratamiento en Git |
| --- | --- |
| Credenciales, archivos de entorno reales, logs, respuestas de prueba y respaldos | Excluidos; sólo ejemplos de configuración y fixtures sintéticos |
| Inventario de AWS y sistemas productivos de woku | Excluido; se conserva arquitectura independiente y resumen operativo |
| Capturas de navegadores de prueba y vistas previas | Excluidas; el código permite revisar la interfaz localmente |
| Reproducciones recortadas de figuras editoriales y de TIC Empresas | Sustituidas por enlaces a las fuentes en la revisión inicial; no se redistribuyen las imágenes |
| Tesis aportada como referencia de escritura | Referenciada bibliográficamente; no se adjunta el documento personal completo |
| Dependencias, bundles y archivos auxiliares de compilación | Excluidos; se incluyen archivos fuente y lockfile |

## Derechos y futura apertura

No se asigna todavía una licencia general al manuscrito ni al código. Antes de abrir el repositorio, sus titulares deben elegir las licencias aplicables a cada material y confirmar la aprobación de los autores. Las dependencias conservan sus licencias; los logotipos y marcas de woku, LinkedIn y WhatsApp no reciben una licencia nueva por estar en el proyecto. Los componentes de interfaz provienen del admin de woku. El certificado CA incluido es el bundle público de confianza de Amazon RDS, no una clave privada.

Antes de cambiar la visibilidad: revisar el historial completo con un detector de secretos; verificar que nuevas capturas, documentos y exportaciones no contengan datos identificables; actualizar el estado del estudio; confirmar permisos de terceros y licencias. Si en el futuro se publican datos, deben tener una evaluación de anonimización y una documentación separada: verificar correo no prueba identidad empresarial. No hay dataset de participantes en esta incorporación.

Los resúmenes de comprobación de software no son resultados de investigación. El manuscrito no contiene datos ni análisis de participantes.
