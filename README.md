## Organización

Las carpetas de estudio siguen `AAAA-tema-region`. Cada una conserva sus versiones históricas y distingue documentos vigentes, código y datos que eventualmente puedan publicarse. Añadir una nueva investigación como carpeta hermana; no mezclar sus dependencias ni instrumentos.

El repositorio se mantiene privado. Está organizado para una futura apertura; cambiar la visibilidad requiere una decisión posterior. [Criterios de publicación y procedencia](PUBLICATION.md). No contiene respuestas individuales ni credenciales de servicios.

## Contribuciones

Documentar cambios sustantivos al instrumento y método antes del trabajo de campo. Mantener autores, fechas, versiones y fuentes. Separar resultados observados de planes o supuestos. No subir datos de participantes, logs con información personal, secretos ni materiales de terceros sin revisar su distribución.
